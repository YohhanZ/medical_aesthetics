## 当前实现与限制

- Vue 3/TypeScript 客户页面已连接真实 LangGraph/Qwen API；服务端持久消息、原键恢复与会话历史，不提供固定假回复。
- 目录及来源来自当前有效已批准公开版本。医疗待审资料不发布，模拟机构标识保留。
- 浏览器 sessionStorage 仅保存 visitor/thread 引用，不存正文、联系方式或模型密钥。刷新恢复自有消息；过期或跨门店拒绝时清理旧数据。
- 显式门店切换重建范围限定的匿名会话。个人医疗问题转专业人员且不推荐项目；waiting 明确人工尚未接通，预约意愿不代表正式预约。
- 摄影素材保存在 frontend/customer/public/images，原始 PNG 在 frontend/customer/assets/source-images；网页 JPEG 共 878,859 字节，保持原像素尺寸，仅编码压缩；项目图片懒加载，首屏图片高优先级。人物细节与移动端裁切已目视检查。生成模式与最终提示词见 [素材记录](image-assets.md)。
- 预约草稿中填称呼、手机号、期望时间、咨询意向和可选项目，核验与确认分步显示。电话不进入模型对话或浏览器存储，页面掩码展示；修改草稿需重新核验。提交显示待门店确认、模拟标识与申请编号，刷新恢复；未知结果保留原键核实，不能重复自动创建。
- 同步返回校验完成的回答；M4 已接授权门店确认/婉拒、改约客户接受/拒绝、客户取消与到店登记。提案保留原安排，客户按钮确认后才改变时间；版本变化清除旧勾选。SSE、真实短信验收、通知/CRM、长期记忆和自助删除仍待实现。开发同源代理不替代生产 HTTPS/反向代理验收。

## 本地运行

Node.js 18.20.4 已检测。两端统一依赖版本以 frontend/package-lock.json 为准。

```powershell
npm --prefix frontend ci
npm run dev
```

客户默认 http://127.0.0.1:5173 。运营后台 `npm run dev:admin`，地址 http://127.0.0.1:5175/#/login 。验证命令 `npm test`、`npm run build` 同时检查两端。后台身份、知识、预约生命周期、到店咨询档案及站内回访已接本地服务；独立项目供给/报价维护和外部通知/CRM仍待接入。没有云部署，不能作为完整生产产品交付。结构和实际接入边界见 [frontend/README.md](../frontend/README.md)。
