# 客户账号与跨会话记忆

## 使用

进入页面先检查客户登录态。未登录时只显示独立的注册／登录页，登录成功后才能进入项目和咨询页面。已有有效登录态直接恢复原会话，不要求再次注册。创建客户账号使用 3–40 位字母、数字、下划线或连字符及至少 10 位密码；账号与后台员工账号独立。换浏览器登录同一账号可恢复同门店的历史聊天、预约及授权偏好。

“我的咨询空间”、偏好明细和行为列表已从客户页面移除。注册时必须主动勾选“允许保存咨询偏好”，默认不预勾选；未勾选时注册按钮禁用，服务端对省略或传入 false 的请求返回 `memory_consent_required`，不创建账号。已有账号登录时该项仍为可选，不需要重复授权，此前已授权的账号不会因未勾选而丢失原偏好。普通前端只读取 `GET /api/customer/session` 的账号摘要，不加载记忆及行为明细。用户主动询问历史偏好时可在对话中回答；普通问候不自动罗列偏好。原偏好设置和删除接口仍保留，暂无客户可视化管理入口。

已有账号恢复该门店原身份，**不会自动合并当前另一个匿名访客的记录**，界面会提示。第一次进入另一门店需再次同意绑定；同手机号不能作为归并依据。未接入短信／微信登录、找回密码或额外匿名记录合并。

## 身份边界

咨询区采用左侧会话列表、右侧聊天布局，手机端通过“历史对话”打开原生模态抽屉；不在聊天区域放时间下拉框。每段咨询由后台生成独立 UUID（接口名为 `thread_id`，不同于登录凭据的 `session_id`）；进入页面／登录后以服务器返回的最新会话为准，不优先恢复浏览器中的旧引用。无历史时才创建首段会话，点击“新建对话”另建一段；刷新不会自动新建。旧会话及消息继续保存，长期偏好按同账号、同门店跨会话读取，不随新建对话清空。时间用于排序和辅助显示，不作为会话标识。

`GET /api/threads` 支持 `limit`（默认 20，上限 100）和 `offset` 分页，严格限定当前身份、机构及门店，返回 `thread_id`、`created_at`、`title`。标题由首条用户问题折叠空白并截取前 24 字生成，空白会话名为“新对话”，不额外发送给模型。列表可继续加载更早会话；选择后读取对应消息，预约面板也按会话重绑，未发送草稿会清空。切换失败保留当前会话，新建成功但列表刷新失败时保留已生成的 ID。前端不持久保存标题和消息，浏览器只记录可选身份／会话引用。

- `customer_account` 为机构内稳定身份，账号名大小写不敏感；不同机构账号不互认。
- `visitor.customer_id` 关联门店内原访客，每位客户在一个门店只有一个稳定身份；门店间记录及偏好分别保存。
- 所有现有服务继续检查 `visitor_id + tenant_id + store_id + session_id`，不放宽会话或预约归属。
- 首次绑定撤销该访客全部旧匿名凭据，再签发带账号信息的新会话。复制旧匿名 Cookie 的浏览器不会获得客户权限。
- 密码使用 scrypt；HttpOnly Cookie、SameSite=Strict、HTTPS Secure、写操作 CSRF、PostgreSQL 登录限流；事务提交成功后才发 Cookie。
- 默认 `MA_CUSTOMER_LOGIN_REQUIRED=true`，服务端同时保护目录、对话、预约及 Agent 执行，无法通过绕开前端直接匿名调用业务接口。连接、登录、退出及最小身份摘要允许匿名启动；后台员工鉴权保持独立。既有匿名兼容测试显式关闭此开关，实际登录门槛另有专门测试。
- 退出或切换门店会清空旧页面消息和对话引用，再返回登录入口。会话有效期沿用 `MA_SESSION_HOURS`；凭据过期后需要重新登录，持久记忆不随 Cookie 过期删除。

## 记忆与行为

`customer_memory` 保存舒适度、到店时间、预算、咨询节奏四类明确偏好。本地保守规则提取固定值，包含来源会话／运行、更新时间及 90 天有效期；同类新表达覆盖旧表达。不处理所有自然语言变体，不保存病史、诊断，不从他人描述或假设推断本人偏好。

每轮按当前账号和门店查记忆，在本地回答用户主动发起的回忆问题，为相关预算／时间咨询衔接上下文，并尊重不接受预约邀请的偏好。记忆不进入 `safe_previous`、`dialogue` 或外部模型请求，不充当医学证据。沙箱只通过已有 Broker 接收有限键值；父进程校验并在返回前重查当前记忆。

运行开始保存 `memory_generation`，设置修改／删除时递增；结束检查版本，防止旧请求或恢复重试重新写入已删除记忆。开启不会回填旧聊天。过期记忆不参与召回。删除偏好不会删除原始聊天、历史助手回答或预约；完整业务数据删除和账户注销尚未接入。

`customer_behavior` 单独保存经同意的项目浏览、分类浏览及每段会话首次咨询。接收白名单事件和门店项目 ID，不保存搜索词、手机号、自由文本或指纹，不把浏览当成已确认偏好。默认关闭，新登录入口不自动开启行为追踪。原后端接口只返回 90 天内最近 30 条，普通客户页面不展示；新事件写入时清理过期事件，关闭记录会删除对应事件。

## 实现

- `backend/migrations/013_customer_memory.sql`：增量迁移。
- `backend/app/customer.py`：账号、绑定、记忆、行为。
- `backend/app/agent_repository.py`：读取、版本校验、持久化与本地个性化。
- `backend/app/consultation_agent.py`、`sandbox_broker.py`：回忆节点和沙箱校验。
- `frontend/customer/src/components/CustomerLogin.vue`：独立注册／登录入口。

接口：`POST /api/customer-accounts`、`POST /api/customer-sessions`、`GET /api/customer/session`（客户页面使用）。偏好管理接口 `GET /api/customer/me`、`POST /api/customer/preferences`、`POST /api/customer/memories/{key}/forget`、`POST /api/customer/behaviors` 保留但无可视化模块。退出复用访客退出接口。
