# 机构运营演示资料包

版本 2026.10.12.1，资料演示期 2026-10-12 至 2026-11-12。

所有机构、人员、地点、报价、产品与供应商档案为虚构演示设定，不代表美丽田园实际资料；模拟通过不是实际资质或供应商验收成功。

本文件与 backend/data/demo_materials.json 是同一套讲解资料。仅新增授权员工只读页面，不导入客户业务表，不自动进入RAG/Neo4j，也不增加外部模型出口。模拟复核人员为虚构角色，不是实际员工授权或独立医学审核。

## 如何演示

1. 启动API8001及后台5175，用既有 demo-consultant 登录，进入“演示资料”。页面只返回授权门店，当前账号只授权上海。
2. “门店与团队”展示空间、营业时段、五个岗位与排班；“服务与演示价”展示十二个服务入口和虚构收费设定。
3. “接待规则”讲解预约确认、改约、隐私和回访。现有真实本地业务页面可演示申请、门店确认、到店建档、意向变化与回访；讲解脚本不伪造客户确认或自动创建业务记录。
4. “供应商演练”展开复核记录及实际验收清单。“模拟通过”和“实际未验收”同时保留，没有短信送达或真实资质声明。
5. “演示讲解”按四条路径讲解，常见问题展开六组建议表达。可下载当前授权门店JSON；完整两城资料见仓库JSON，仅用于开发演示，不能当成查询另一门店客户的接口。

建议5分钟顺序：机构与团队1分钟→服务与示例价1分钟→客户咨询/预约/到店档案2分钟→回访/暂停/供应商边界1分钟。无真实短信发送、电话或外部CRM连接。

## 接待规则

### 预约与接待

线上先提交申请，由门店核实时间后确认；可以先咨询、不选定项目。

演示流程：预约申请→明确客户确认→门店核实。

### 费用说明

演示报价仅用于页面讲解；服务前逐项说明包含内容和不包含内容，不自动收费。

演示流程：查看演示价→到店说明→独立确认。

### 改约与取消

客户可提出调整时间；新安排须本人明确同意，原时间和处理历史保留。

演示流程：门店提案→本人回应→状态同步。

### 隐私与权限

客户只读取自己的对话与关联业务；员工只访问明确授权门店，内部备注不对客展示。

演示流程：访客Cookie→门店授权→审计。

### 回访与暂停

回访逐次同意；拒绝或取消暂停新邀请，仅客户本人可恢复。

演示流程：站内邀请→本人同意/拒绝→反馈。

### 医学与资料审核

医学个人判断转专业人员；资质、产品注册及医学内容实际核验前保持待审。

演示流程：公开了解→待审资料→独立审核。

## 演示路径

### 首次了解 → 预约 → 门店确认

演示客户林女士为讲解化名。讲解脚本，不是持久客户业务记录。

1. 询问补水护理
2. 查看回答与关联卡片
3. 表达到店意愿
4. 模拟核验并明确确认申请
5. 门店核实原时间并确认

预期：待门店确认→已确认；项目可未定。

### 到店 → 意向调整 → 本人确认

演示客户周女士为讲解化名。讲解脚本，不是持久客户业务记录。

1. 员工核实模拟到店
2. 顾问建档保留原意向
3. 追加新的咨询意向版本
4. 客户审阅并明确确认
5. 后台刷新历史

预期：旧确认不应用于新版本。

### 回访同意 → 反馈 → 内部跟进

演示客户叶女士为讲解化名。讲解脚本，不是持久客户业务记录。

1. 从已确认意向提出站内计划
2. 原访客明确同意
3. 客户提交希望继续沟通
4. 顾问追加内部记录
5. 检查客户看不到内部备注

预期：反馈已保存，不宣称人工已回复。

### 拒绝回访 → 暂停 → 本人恢复

演示客户程女士为讲解化名。讲解脚本，不是持久客户业务记录。

1. 客户拒绝站内邀请
2. 顾问新邀请被阻断
3. 客户本人恢复邀请
4. 提出新计划
5. 新计划重新等待客户同意

预期：员工不能代为恢复。

## 接待表达

### 不确定项目，可以先到店聊吗？

可以先聊您的关注方向，项目也可以到店后再确定。若您想预约，我们先核对申请内容，再由门店确认时间。

### 先了解一下大概费用？

演示资料列出了单次护理体验的示例价格和包含内容。实际服务与收费需门店核实，您可以先了解，不必现在决定。

### 时间有变，可以改约吗？

可以沟通调整。门店提出新时间后，会请您确认；确认前仍保留原安排。

### 门店会看到哪些信息？

您只能读取自己的对话和关联记录，员工按授权门店访问。门店内部跟进与客户可见内容分开保留。

### 暂时不需要回访可以吗？

可以拒绝或取消本次站内回访，新邀请会暂停。以后您愿意继续时，可以本人恢复，新的计划仍需逐次同意。

### 可以直接帮我判断适合哪个医美项目吗？

可以先介绍相关公开了解入口。个人适合性和医学方案需要核验资料及专业评估，我会说明转专业人员的原因。

## 工程与验收边界

GET /api/stores/{store}/demo-materials 要求有效员工Bearer和当前门店customer_read，读取审计；只在显式启用模拟资料的非生产环境、模拟活动门店可见。访客、未授权员工、平台管理员默认、另一门店和生产环境均拒绝。不新增grants、不覆盖密码或.env、不改既有迁移、不提交/推送。

本包补演示资料，不代替M6备份恢复、生产部署、真实供应商验收和医学核验。具体测试与浏览器实测见 [实施记录](production-readiness.md)。
