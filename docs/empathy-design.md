# 情绪识别与共情回应

2026-10-12 用户要求将共情话术接入实际咨询。当前实现有限本地规则识别普通顾虑、预算压力、低落/疲惫、外貌评价、销售反感、希望暂停、需要陪聊与状态改善；不是心理诊断或经过训练的通用情感分类模型。

## 实际路径

纯情绪表达进入LangGraph的support路径，不初始化外部模型/检索客户端，不展示项目卡片、不触发预约。回应从当前门店已独立审核、发布、有效且投影就绪的公开沟通知识中选择；有两种表达变体。暂停回应不追加问题。缺少有效话术时只给固定礼貌回应，不继续使用撤回或过期脚本。

情绪与事实问题同时出现时，本地先将问题投影为项目名称和明确公开任务，再做现有RAG与Qwen生成，最后本地添加共情开场。例如“失恋很难过，想了解补水步骤”外发的是补水内容/步骤问题；“预算压力大”未主动提问时只安慰。拒绝预约同时问护理内容时仍回答内容，不把拒绝当作结束答疑；暂停或拒绝销售停止邀约。

正文情绪、关系细节、个人医疗、身份与业务记录不进入模型请求。result.public_answer仅保存已验证的公开事实部分，供后续步骤追问；与展示给客户的共情完整answer分开。Gateway再次投影问题并排除带情绪措辞的历史答案。纯情绪消息exportable=false，混合问题允许的只是公开投影。checkpoint与短期摘要不存原情绪正文或情绪类别，不做跨会话情绪画像；原始聊天仍在本人授权的本地会话记录中。

“担心光子”可以保留当前公开项目的本线程来源引用，随后“一般风险有哪些”接上光子。仅对本人已完成且无转接原因的support消息允许本地解析来源，重新校验分类和当前目录，仅项目标签作为后续模型语境；thread_id不是凭据，不放宽跨线程读取。临床/身份/越权消息不能借该分支成为来源。

个人症状、病史、孕期、诊断/药物仍先本地专业转接。自伤/轻生表达进入本地安全回应，不生成项目推荐或预约卡；crisis_pending仅本地安全流程状态，后续普通项目追问仍先关注安全，明确本人当前安全且没有新的危险表达后可回到公开介绍，不表示医学批准。否定安全声明不会清除此状态。安全回应参考[WHO公开说明](https://www.who.int/news-room/questions-and-answers/item/suicide)，不提供未经核实的热线或冒充人工已接通。

输出拒绝“你有抑郁症”等心理诊断、制造“不做越来越丑”的焦虑、医美治愈情绪/挽回关系承诺，以及原有不支持价格、疗效、安全或业务完成声明。未验证草稿不提交，模型失败仍能在有效来源下先共情再安全降级。有限规则不能识别所有隐喻、否定和复合意图；需持续扩充语义及对抗评测。
