# 美丽田园客户咨询与机构管理平台

当前阶段：M5 到店咨询与站内回访已接入，2026-10-12。两个 Vue 3 应用集中在 frontend/；后台员工身份、知识管理、预约生命周期与到店意向记录已接本地 API。知识 264 条，Milvus 239 条真实向量与 Neo4j 投影就绪，医学 25 条待审。客户首页无需员工登录，支持真实 Qwen 回答、关联追问、历史恢复与有效项目图文；上海模拟目录有 30 个入口。预约支持客户确认提交、门店确认/婉拒、改约本人回应、客户取消和到店登记。顾问从已到店预约建立独立咨询档案，保留原意向，变更追加新版本；客户在原对话中确认或继续沟通，每次修改重新等待本人确认。站内回访逐次由客户同意，支持反馈、暂停/恢复邀请和门店内部跟进；内部备注不显示给客户。核验、业务资料与档案保留模拟标识。真实短信供应商、通知/CRM、注册后长期记忆与生产部署待完成，当前不是完整生产上线交付。

目标：统一承接美容护理与医疗美容咨询，帮助新客户了解服务并提交到店预约申请；门店确认后才成为已确认预约。客户到店后继续补充资料、咨询及调整意向项目。

演示资料：已准备两家虚构门店、10个岗位、24条服务/虚构报价、12条接待规则、4家虚构协同供应商及模拟独立复核、6组接待表达和8条讲解路径。后台“演示资料”只读展示并可下载当前授权门店JSON；使用既有demo-consultant上海顾问登录。资料不自动发布到Agent知识库，实际资质/供应商仍待核验。

前端安装：`npm --prefix frontend ci`。先启动本地 API，再执行 `npm run dev`，打开 http://127.0.0.1:5173 。后台执行 `npm run dev:admin`，打开 http://127.0.0.1:5175/#/login 。目录、接入状态和运行方法见 [前端说明](frontend/README.md)。预约入口进入真实对话，客户明确确认后才生成持久申请；本地模拟申请不是实际门店可约承诺。

服务端启动与验收：[backend/README.md](backend/README.md)。本地 API 使用 8001 端口、独立数据库使用 55434 端口、独立 Neo4j 使用 57689 端口、Milvus 使用 59531 端口。当前开发库 239 条非医学知识已完成真实 256 维向量与图谱投影，25 条医学资料待审。31 条合成独立问题的真实混合检索 recall@5 为 30/31；这是本地小集结果，不代表完整智能咨询、医学效果或生产容量。

远程仓库：https://github.com/YohhanZ/medical_aesthetics.git

所有未注明已核验的项目、价格、门店与人员资料不得视为美丽田园实际供给。合成销售策略不得冒充真实员工经验。医学资料需要独立审核，模拟审核不得用于真实医疗上线。

## 共情咨询（2026-10-12）

已接入情绪识别和共情回应：普通担忧/低落先安慰，明确事实问题继续回答，暂停停止追问。新增 30 条知识真实向量化/图谱投影，当前主库 340 个发布版本含历史，不等于全部当前公开资料；25 条原医学待审保留。打开 http://127.0.0.1:5173/#consultation 新建对话，可输入“我今天心情不好”→“担心预算，补水护理多少钱？”→“我想静静，不想说了”。有限规则、隐私与测试边界见 [共情设计](docs/empathy-design.md)。

## Agent运行时沙箱（2026-10-12）

咨询新执行默认进入独立离线Docker容器；先在backend执行 `docker build -f sandbox/Dockerfile -t medical-consultation-sandbox:local .` 再启动8001 API。无网络/宿主挂载/密钥，父进程白名单Broker负责授权服务和最终校验；生产拒绝inprocess。Docker/镜像不可用不回退，health/ready可见agent_runtime=docker。源码、验证、面试回答和剩余边界见 [运行时沙箱](docs/runtime-sandbox.md)。
